## 简介

《王国: 两位君主》玩家的随身工具。输入你玩到第几天，即可推算:

- **血月**在哪天来（红色警示，提前布防）
- **平安日**哪天休（安心发展经济）
- **季节更替**节奏（冬储粮、春扩张）
- **换岛窗口**（挑战岛·商路的夏/冬岛循环）

页面背景与游戏内昼夜实时同步: 1 游戏日 = 4 现实分钟，日月沿轨道运行、天空随时间变色、季节粒子飘落，进度条支持**手指拖动预览任意时刻**的昼夜状态。当天数以游戏同款像素哥特罗马数字（`ccclxix`）呈现。

## 功能特性

| 功能 | 说明 |
|---|---|
| 血月 / 平安日 / 换季 / 常规日 判定 | 数据整理自游戏实测（贴吧考据 + 游戏代码） |
| 5 种模式支持 | 标准战役、北欧之地 DLC、Dead Lands DLC、奥林匹斯的召唤 DLC、挑战岛（商路 / 骷髅 / 瘟疫 / 恐怖 / 失落） |
| 昼夜实时时钟 | 与游戏内 1:4 时间流速同步，太阳月亮轨道运行，天空渐变 |
| 进度条触摸拖动 | 按住昼夜进度条左右拖，预览当天任意时刻的天空与日月位置 |
| 罗马数字天数 | 游戏同款风格的天数展示 |
| 未来 7 天速览 | 一眼看随后 7 天的日型，便于规划 |
| 倒计时 | 距下次血月 / 距明天开场的实时倒计时 |
| 状态记忆 | 重进小程序自动恢复上次的模式与天数 |

## 支持的模式

| 模式 | 天数范围 | 规则 |
|---|---|---|
| 标准战役 | 1 – 639 天 | 固定血月表，639 天后按第 10 年节奏外推 |
| 北欧之地 DLC | 1 – 639 天 | 固定血月表 |
| Dead Lands DLC | 1 – 639 天 | 固定血月表 |
| 奥林的召唤 DLC | 1 – 639 天 | 固定血月表 |
| 挑战岛 · 商路 | 无限 | 循环制: 夏岛 107 天 / 冬岛 96 天一周期 |
| 挑战岛（骷髅/瘟疫/恐怖/失落） | 无限 | 循环制 |

## 使用方法

1. 微信扫码或搜索打开小程序
2. 选择游戏模式（DLC / 挑战岛需要再选具体岛屿）
3. 输入当前天数，或用 +1 / −1 步进
4. 底部时钟卡自动按真实时间推进昼夜；拖动进度条可快进/快退预览

## 数据规则（考据说明）

- 血月日期表来自社区实测考据: [贴吧整理帖](https://tieba.baidu.com/p/11082735902)
- 商路两岛确认为循环制: 永恒夏季岛 107 天/周期，永恒冬季岛 96 天/周期，无限循环
- 战役类模式超过 639 天后，按第 10 年节奏外推（锚点第 576 天，64 天/年）
